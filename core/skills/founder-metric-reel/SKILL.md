# Founder Metric Reel

## Purpose

Produce Instagram reels where Robbie (the founder) explains a real technical achievement the way Reflex's CEO Lucas does: one big number, a high-level breakdown of how it was achieved, and a cost pain-point that makes the viewer care. Method distilled from @tryreflex reel "Kimi K3 at 490 tokens/sec with 6x the context" (https://instagram.com/p/Dd7C4ZeAxZy/, posted 2026-09-30). Their numbers are THEIR claims from a reel, unverified; the format below is the transferable part. Every number WE put on screen must be real, measured, and attributable per the sourced-claims house rule.

## The format (4 beats)

### Beat 1 — Big-metric hook (first 3 seconds)
One number on screen, said out loud. Not a tip, a result.
- Theirs: "Kimi K3 at 490 tokens/sec with 6x the context."
- Ours: a measured Kingmaker number — latency, tokens/sec on local hardware, tasks completed without intervention, dollars of API spend avoided. Must be a number we actually measured, with the measurement conditions noted (hardware, model, date).

### Beat 2 — Founder breaks down HOW (the body)
Talking head, direct to camera. High-level explanation of the mechanism behind the number — architecture, not marketing. "Here's how we're achieving these numbers."
- Keep it high-level: the viewer should understand the *idea* (e.g. "the router picks the cheapest model that can do the task, and proves it in the audit trail"), not the implementation.
- Show the receipts on screen where possible: terminal output, dashboard, the actual system running. Never describe a system when you can demonstrate it (standing format rule).

### Beat 3 — Cost pain-point bridge
Connect the number to the viewer's wallet. Theirs: "API costs can quickly become a huge pain for your wallet, but they don't have to."
- Ours: per-second API billing, per-token metering, the hardware tax — always tied to a real, named cost the buyer recognizes. This is the headline-doctrine slot: "Their X [known weakness]. Kingmaker [provable outcome]."

### Beat 4 — Engagement question CTA
End on a genuine question, not a pitch. Theirs: "What's your opinion on frontier open-source models?"
- Ours: a question that starts a fight in the comments AND funnels DMs (e.g. "What's the most you've ever paid for an API bill that did nothing?"). Close with the DM keyword CTA per the funnel rule.

## Fusing with Robbie's standing rules

- **Sourced claims (hard):** every number on screen is measured by us, with conditions. No borrowed numbers, no "studies show," no Reflex-style unverified claims presented as ours.
- **Headline doctrine:** on-screen comparisons pair explainable outcomes against closed flagships only ("Their X. Kingmaker Y."). Open-source projects are never targets.
- **Buyer audience:** the pain point and CTA aim at operators who can buy bespoke work — not generic AI-curious viewers.
- **Noir grade:** dark Ronin schema, evidence-dashboard visual language. The founder's face is the evidence; slides support, never replace.
- **Honest turn:** say what didn't work on camera where it's true (the standing format's adversarial honesty). A metric with a caveat beats a metric with an asterisk.
- **Kingmaker / DIM OS:** never appear, per standing confidentiality rules.

## Production recipe

1. **Pick the metric.** One measured number from a real Kingmaker run. Write down the measurement conditions (machine, model, task, date).
2. **Write the 4-beat script.** Hook (number) → how (high-level mechanism) → wallet bridge → question CTA. 45–75 seconds spoken.
3. **Shoot talking head.** Robbie direct to camera, handheld mic per the standing format. B-roll: the actual system producing the number on screen.
4. **On-screen cards.** The metric as a card in the first 3 seconds; the headline-doctrine comparison as a card in beat 3; the question as the end card.
5. **Caption.** Big number + one-line context + the wallet pain + the question + DM funnel CTA + ronininc.org link. Hashtags: #governedai #localai + topic tags.
6. **Music.** Kevin MacLeod "Meditation Impromptu 01" (CC-BY 4.0) with credit, matching the other reels — unless Robbie picks otherwise.

## What this skill does NOT do
- It does not invent metrics. No metric, no reel — go measure something first.
- It does not publish. Robbie approves every reel before it ships.
- It does not copy Reflex's content, branding, or claims — only the 4-beat structure.

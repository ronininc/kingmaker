# Stage 1 — Market & Criteria Setup (the buy box)

Pull nothing until the buy box exists, or the list is noise and the team burns
skip-trace and mail dollars on leads they'd never buy.

## Capture these (ask only for the ones that change the output)
- **Geography:** county / city / ZIP(s). Virtual is fine — note the team may not
  know the market, so lean harder on data and local title/agent partners.
- **Property type:** SFR, 2–4 unit, condo/townhome, land, small multifamily.
- **Price / ARV band:** the buyer demand sweet spot for the area.
- **Condition appetite:** light cosmetic vs. full gut — sets the repair tier used
  in Stage 5.
- **Motivation lists to pull:** which of the Stage-2 list types (default to
  pre-foreclosure + tax-delinquent + absentee + probate if unspecified — the four
  highest-yield).
- **Exit strategy:** assignment to cash buyer (default), double close, novation.
- **Assignment fee target:** typical $5k–$25k; sets the spread math in Stage 5.
- **Volume goal + cadence:** deals/month → how big a list to pull.

## If unattended / user didn't specify
State the assumptions at the top of the deliverable and proceed with the defaults
above rather than blocking. The user can correct and re-run cheaply.

## Output
Write the buy box into the header rows of `assets/lead-sheet-template.csv` (or the
CRM), so every downstream stage inherits the same targeting. Confirm it back to
the user in one short block before pulling lists.

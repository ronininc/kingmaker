# Stage 7 — Assignment & Close (title / TC)

Get the deal to the closing table and get the assignment fee paid.

## The closing packet MUST contain (check every item)
A deal is not "closing-ready" until the packet has all of these. Produce each as a
real file; mark any data gap `VERIFY`, never fabricated.
1. Executed **PSA** (`assets/purchase-and-sale-agreement.md`) with assignment clause + inspection contingency.
2. Executed **Assignment Agreement** (`assets/assignment-agreement.md`) with the fee.
3. **Seller Authorization to Release Information** (`assets/seller-authorization-to-release.md`)
   — REQUIRED on any pre-foreclosure / behind-on-payments / lien deal so title can pull
   the payoff. Generate and get signed EARLY.
4. **Seller disclosures** (`assets/seller-disclosures.md`) — auto-include the
   **lead-based-paint disclosure whenever year built < 1978**, plus the state
   condition form (AZ SPDS, CA TDS, etc.).
5. **Payoff / reinstatement solvency check** (distressed): order the payoff via title;
   **if payoff > MAO, STOP the straight assignment** and escalate (short sale /
   subject-to / reinstatement). Confirm the **trustee-sale / auction date** and set the
   close before it.
6. **Title order + lien check**, **proof of funds** (buyer), **earnest money** receipt,
   and a **settlement statement showing the assignment fee** as a line item.
7. **Deliverables**

**Assignment Agreement** (if not already generated in Stage 5) —
   `assets/assignment-agreement.md`, filled with the end buyer and the assignment
   fee. Discloses the fee where the state/contract requires.
8. **Closing checklist** — the standard path:
   - Executed PSA (seller ↔ wholesaler) delivered to title/attorney.
   - Executed Assignment (wholesaler ↔ end buyer).
   - Earnest money receipted.
   - Title search / commitment ordered; clear any liens found (tax, mechanic's,
     HOA) — distressed deals often carry these.
   - Buyer's proof of funds verified.
   - Closing scheduled; assignment fee shown on the settlement statement (or paid
     per the agreement).
   - Signed docs + IDs to the closing agent.
3. **TC / title handoff packet** — bundle the above for the transaction coordinator
   or title company.

## The vendor relationship (per-market setup, not a tool)
Wholesaling needs an **investor-friendly title company or closing attorney** that
handles assignments/double closes. This is a relationship the team establishes in
each market — flag it as a setup task, and note that some states require an
attorney at closing.

## Pipeline / TC tooling
REsimpli, InvestorFuse, REI BlackBook, or Podio for tracking; DocuSign/Dotloop for
signatures; Google Drive for doc storage.

## Legal stamp
Assignment mechanics, fee disclosure, and license requirements vary by state (some
now restrict or license wholesaling). Confirm with local counsel — see
`references/compliance-and-legal.md`. The skill prepares the packet; it does not
replace the closing attorney or title company.

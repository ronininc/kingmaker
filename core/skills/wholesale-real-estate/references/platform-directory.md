# Platform Directory (by stage, with current pricing)

Pricing is approximate and moves; verify on the vendor site before quoting a team
budget. Always attempt the free/public method first (see each stage reference),
then use this table to tell the team which paid tool does the stage faster or at
scale, and why.

## Stage 2 — Lead lists / data
| Platform | What it does | Rough price |
|---|---|---|
| **PropStream** | Category standard. Nationwide property data, 100+ list filters (pre-foreclosure, tax lien, absentee, vacant, loan type/FHA), comps, built-in skip tracing | ~$99/mo |
| **BatchLeads** (merged w/ PropStream) | List building + skip tracing + SMS + driving-for-dollars | Subscription |
| **PropertyRadar** | Deep list/data + dynamic monitoring lists; strong CA/foreclosure data | Subscription |
| **Propwire / Propelio / Leadflow** | Lower-cost data + comps; Leadflow adds AI "sellability" scoring | $ / affordable tiers |
| **Foreclosure.com** | Dedicated foreclosure/auction/HUD listings + alerts | Free alerts / paid full |
| **HUDHomeStore.gov** | Official FHA-foreclosure inventory | Free |

## Stage 3 — Skip tracing
Included in PropStream, BatchLeads, DealMachine, Propelio, Deal Run.
Standalone/bulk & higher accuracy: **BatchSkipTracing, Skip Genie, IDI/LexisNexis**.

## Stage 3b — Driving for dollars
| **DealMachine** | Category leader; mileage tracking, on-the-spot skip trace + mail | ~$49–99/mo |
| **BatchLeads, Propelio** | Also have D4D route/capture modes | Subscription |

## Stage 4 — Outreach & marketing
- **Cold call / power dialer:** Mojo, BatchDialer, CallTools, REsimpli dialer
- **SMS / text blast:** Launch Control, Smarter Contact, BatchLeads, Roor (10DLC required)
- **Direct mail:** DealMachine, FreedomSoft, Realeflow, REsimpli (yellow letters, postcards)
- **PPC / inbound seller sites:** Carrot (SEO seller-lead sites — the standard), Leadflow

## Stage 5 — Acquisition
- **Comps / ARV / valuation:** PropStream, Propelio, PropertyRadar, Privy, MLS (gold standard w/ agent access)
- **Deal analysis / MAO:** Flipster, Realeflow, Deal Run, DealCheck
- **Contracts + e-sign:** templates in REsimpli/FreedomSoft/REI BlackBook; sign via DocuSign / PandaDoc / Dotloop

## Stage 6 — Dispositions
| Platform | Role | Price |
|---|---|---|
| **InvestorLift** | Big-league buyer marketplace + blast engine ("Dispo") | $6K–$15K+/yr |
| **Deal Run** | Buyer identification + AI comps + repair estimates | ~$99/mo |
| **InvestorBase** | Ranks likely cash buyers from public records | ~$249/mo |
| **REsimpli** | Dispo built into the CRM (email/SMS to buyer list) | $199–$499/mo |
| **Privy** | Buyer/investor activity + comps | Subscription |
Plus: your own cash-buyer list (public-record cash/absentee purchases) + Facebook buyer groups.

## Stage 7 — Assignment & close
- **TC / pipeline:** REsimpli, InvestorFuse, REI BlackBook, Podio (custom builds)
- **Title / closing:** investor-friendly title company or closing attorney (vendor relationship, per market — not a tool)
- **E-sign + doc storage:** DocuSign / Dotloop / Google Drive

## CRM spine (all stages)
| REsimpli | All-in-one favorite (CRM + dialer + dispo + mail + accounting) | $149–$599/mo |
| InvestorFuse | Workflow / lead-response focused | ~$150/mo |
| FreedomSoft | CRM + list + mail + websites | ~$197/mo |
| REI BlackBook | CRM + analyzer + phone system | Subscription |
| Podio + GlobiFlow | Customizable/budget build-your-own | Free–$24/user + add-ons |

## Lean starter stack (new team)
Data/lists+skip → **PropStream**. Field leads → **DealMachine**. Outreach →
**Launch Control** (SMS) + **Mojo/BatchDialer** (calls). Inbound → **Carrot**.
CRM/pipeline/dispo/mail → **REsimpli**. Buyers → **Deal Run** (then **InvestorLift**
at volume). Contracts → PSA + Assignment on **DocuSign**. Realistic all-in tooling:
**~$400–$1,200/mo** before mail/ad spend.

# Stage 4 — Outreach & Marketing (make contact)

Deliverable = a ready-to-run campaign, not advice. Produce the scripts/sequences
from `assets/outreach-scripts.md`, tuned to the motivation list (a pre-foreclosure
owner and a tired landlord get different first lines).

## Channels + the paid senders
- **SMS / text blast** — highest response for cost. Paid: **Launch Control,
  Smarter Contact, BatchLeads, Roor**. Requires **10DLC** registration.
- **Cold call / power dialer** — Paid: **Mojo, BatchDialer, CallTools, REsimpli**.
  Must be DNC-scrubbed.
- **Direct mail** (yellow letters, postcards) — Paid: **DealMachine, FreedomSoft,
  Realeflow, REsimpli**. No DNC/10DLC issue; slower, higher cost per touch,
  strong for probate/absentee.
- **Inbound / seller sites (PPC + SEO)** — **Carrot** is the standard for
  motivated-seller landing pages; **Leadflow** for lead flow.

## Method
1. Pick channel(s) by list type and the team's tooling.
2. Generate the sequence: first touch + 3–5 follow-ups (follow-up is where deals
   are made; most sellers convert after several touches).
3. Personalize by motivation and property, never with fabricated specifics.
4. If a connector is available (Gmail, an SMS API), the skill can draft/queue real
   sends — **only after** the compliance flags below are acknowledged.
5. Log each touch in the CRM (`Status → Contacted / Follow-up`).

## Compliance (do not skip — read `references/compliance-and-legal.md`)
- **TCPA + DNC:** scrub call/text lists against the National DNC Registry; honor
  opt-outs immediately; mind state calling-hour rules.
- **10DLC:** SMS must go through a registered campaign/brand or carriers block it.
- **Honesty:** don't imply the team is a licensed agent or a direct all-cash buyer
  if that's not true; disclose the wholesaler role where the state requires it.

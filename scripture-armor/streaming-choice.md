# Choose how Scripture Armor is installed on this device

FULL BUILD — always loaded, always aware
The large download. Everything Scripture Armor needs is installed on this device, including the full analysis runtimes. It is always loaded and omni-aware: it watches continuously, including between jobs. It works with no connection at all.

STREAMING BUILD — light, loaded on demand
The small install. Scripture Armor's local core (scanner, vault, policy) is installed, but the heavy capability is not: the first time you call a function that needs it, that capability is pulled in portions over a connection, so a connection is needed when something new is first called. What has been pulled stays on the device and is managed by a daily churn scan that verifies what is held, refreshes what the library has superseded, and removes what is stale, so the install stays small.
Because it is loaded on demand, the streaming build is invocation-aware only: it knows what it is called to do, when it is called. It is not watching between calls. If you want omni-awareness, choose the full build.

Either build can be chosen on any device. A small device may take the full build; a large device may take streaming.

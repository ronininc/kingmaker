# Booking Barbershop Services App

Generated by **Ronin App Forge** from this brief:

> A booking app for my barbershop with services, staff, and appointments, plus a customer login

## Run it
Open `index.html` in a browser. It's a self-contained CRUD app for: Appointment.
Data is stored in your browser's localStorage.

## Wire a real backend (optional)
This app was scaffolded to run with zero backend. To persist centrally, connect the provisioned
Supabase/PocketBase instance (see `app-spec.json` for the schema) and replace the localStorage calls
in `index.html` with REST calls to your BaaS. App Forge can regenerate against a live BaaS URL.

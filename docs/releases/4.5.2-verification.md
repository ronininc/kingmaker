## Executed checks

- Complete project tests, including add-ons: **1,690 tests; 1,650 passed; 1 failed; 39 skipped**. The remaining failure is missing Linux/Windows portable installer source. This is not a fully green cross-platform suite.
- Final installer policy suite: **23/23 passed**, including signature refusal, rollback, resumability, no model pulls or corpus bootstrap, preservation of existing corpora, and explicit availability inventories.
- Launcher: **174 Rust + 128 JavaScript tests passed**; actual built signed binary started. Its issued archive and installed-bundle fingerprints are recognized by Kingmaker.
- Full signed app archive: 2,333,921,280 bytes compressed, 4,485,619,712 bytes unpacked. Two parts were re-read and verified, fully extracted, compared against the signed source app and checked using actual `codesign -R` evaluation of the required release certificate. Installer and Launcher source provenance passed the gate.
- Exact built installer installed the real app and Launcher into an isolated prefix. The installed app passed strict signature and deep payload verification (2,023 files), reported version 4.5.2 and served `/api/health` with HTTP 200. The installed Launcher matched its issued identity.
- The isolated installation's only network request was a localhost Ollama `/api/tags` inventory. No model weights or corpora were transferred. Shared-tool installation and live owner onboarding were not exercised by this prefix test; the owner's installed application was unchanged.
- All seven GitHub assets matched their expected SHA-256 and byte length. Anonymous downloads of the installer, Launcher, manifest, detached signature and checksums matched local release bytes; the downloaded manifest signature verified against the pinned public key. Anonymous requests to both large parts succeeded.

## Launcher-first installation blocker

A subsequent check of the real Launcher 0.3.18 placement path found a blocker: after verifying the release manifest, it passes the entire Kingmaker product through generic connector REA scanning, which rejects the app. The isolated installation above used the standalone installer, not this Launcher-driven path. Do not describe Launcher-first installation as verified or usable until the dedicated authenticated-product placement fix is released and tested. The standalone installer path remains the tested installation route. Generic arbitrary-app scanning must not be disabled to work around this.

## Scope and limitations

This is a macOS arm64 release, minimum macOS 14.0. Installer and Launcher carry Developer ID signatures; Kingmaker retains its established release certificate. These artifacts are not notarized. Do not advertise warning-free installation on a fresh Mac.

Installation inventories existing models and corpora, without automatically downloading them. A receipt indicating existing corpus presence is not a fresh content-integrity or retrieval proof. Missing data and inference must be configured explicitly. First-run ownership/permissions still require the owner.

These checks do not certify arbitrary-model streaming, universal weight conversion, autonomous AAA game generation, photorealistic production quality, or live paid Scripture Armor integration. Armor activation and paid capabilities remain a separate product boundary.

The complete downloadable `SHA256SUMS` includes both app parts, Launcher, installer DMG, manifest and its detached signature. No private signing keys were exported or rotated.

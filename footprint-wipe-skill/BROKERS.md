# Broker & exposure directory — footprint-wipe reference

Verify each entry live at run time (Prime Rule 4): start from the service's own
privacy page and follow its current opt-out path. Entries name the service and
the channel class, not frozen deep links — those rot.

## People-search & data brokers (opt-out / suppression)

- Whitepages — suppression request via its privacy center
- Spokeo — opt-out page (listing URL required)
- BeenVerified — opt-out search + removal form
- PeopleFinders — opt-out / record removal
- FastPeopleSearch — removal request form
- TruePeopleSearch — removal request form
- Radaris — listing control / removal request
- MyLife — removal via privacy request (persistent; re-check often)
- Intelius / PeopleLookup — suppression via its privacy center
- ThatsThem — opt-out form
- Nuwber — listing removal request
- USPhoneBook — opt-out form
- ClustrMaps — listing removal request

## Marketing-data holders (rights requests / consumer opt-out)

- Acxiom — consumer opt-out portal
- Epsilon — consumer request portal
- LexisNexis — consumer disclosure + opt-out ( freezes are a separate, stronger act — owner's individual call)
- Oracle Data Cloud / BlueKai — opt-out registry
- LiveRamp — data deletion / do-not-sell request

## Search engines

- Google — "Results about you" (personal contact info removal) + standard removal requests for owned pages
- Bing — content removal request (mirrors Google for contact data in many cases)
- DuckDuckGo — no index of its own for this purpose; fixing the source + Google/Bing covers it

## Breach presence (check-only — drives password hygiene, not removals)

- Have I Been Pwned — email lookup
- Firefox Monitor — same corpus class, second opinion

## Notes

- Some brokers demand an ID upload for rights requests. That is a hard stop:
  surface it to the owner as its own decision, never a routine step.
- Family/relative listings often expose the owner sideways (address history,
  "possible relatives"). Phase 1 records these; removing them is the relative's
  own act — outside this skill's owner-only rule. Name them in the report so
  the owner can have the conversation, not the skill.
- Expect 30–90 day removal windows and silent re-listing. The wipe log is the
  source of truth for what was filed, when, and what came back.

---
id: m06-prebuild-customer-research
name: Pre-Build Customer Research
source: Angus public post 2026-07-21 (research system run before building)
trigger: a product/feature is proposed, before any build order is written
inputs: the proposal, public sources (reviews, forums, competitor pages)
tools_local: browser research, local model synthesis
approval_gates: none; the research informs the build decision, it never green-lights one
outputs: demand evidence file: who hurts, current workarounds, willingness signals, kill criteria
---
Steps:
1. State the proposal's falsifiable demand claim in one sentence.
2. Gather public evidence for and against; the against column is mandatory.
3. Apply the one rule from the source post: never let the model answer as the customer — evidence quotes or it didn't happen.
4. File with a build / kill / dig-deeper recommendation and the kill criteria for the build if it proceeds.
Stoppers: public sources only; no pretexting, no fake accounts, no review scraping behind logins.

id: m01-second-brain-audit
name: Second-Brain Business Audit
source: Angus public post 2026-10-20 (title-level catalogue; technique re-implemented clean-room)
trigger: owner asks "what's my real problem" / periodic audit tap
inputs: owner's own connected sources (CRM export, mail, notes, journal) — owner data only
tools_local: local model (router-selected), file readers, CRM read access
approval_gates: none to read; the audit REPORT is delivered, never acted on without a tap
outputs: ranked problem list with evidence pointers per claim
---
Steps:
1. Pull the owner's own records for the window (default 30 days): deals, messages, notes, tasks.
2. Local model clusters activity by project/client and flags mismatches: effort vs revenue, open loops, repeated manual work.
3. Every claim in the report cites the record it came from (path/id + date). No uncited claims.
4. Deliver as a tap-session brief: top 3 problems, evidence, one recommended move each.
Stoppers: none. Owner's own data only; never run against another person's records.

id: m15-self-teaching-loop
name: Self-Teaching Loop
source: Angus public post 2026-08-18 (replace Coursera: learn anything with an agent + notebook)
trigger: owner or a rep needs a new skill domain
inputs: the target skill, a source corpus (docs, courses the owner already owns, public material)
tools_local: local model tutor, notebook of worked examples, spaced recall checks
outputs: a study path with mastery checks; progress filed to Academy where it concerns reps
---
Steps:
1. Define the terminal capability in one sentence (what the learner will DO, not know).
2. Tutor works from the corpus only; every lesson ends with a production task, not a quiz summary.
3. Recall checks at expanding intervals; failures loop back as new lessons.
Stoppers: none. Corpus rights respected — owned or public material only.

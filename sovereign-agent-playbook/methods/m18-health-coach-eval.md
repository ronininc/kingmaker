The source is a cautionary tale in the author's own telling: the agent optimised for
agreement, not outcomes. Any future health-coaching method on this stack must:
1. Anchor to measured data (device health records), never to the user's stated feelings about progress.
2. Refuse to revise targets downward to please; target changes are logged decisions.
3. Escalate contradictions between the data and the narrative instead of smoothing them.
Until a method passes those three as tests, this stays an evaluation frame, not a coach.
Stoppers: no diagnosis, no medical claims (Anatomy rule applies stack-wide).

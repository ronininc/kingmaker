# Method — Blender still render (scene script + job record)

A method file (owner item 15): read by the conductor (`lib/method-conductor.mjs`) and executed
step by step. For a render-class request: turn the subject and the dials below into a real,
runnable Blender scene script and a job record, verify both, and declare the render run with
the exact command for this machine.

This is generative capacity that is not a language model (owner, 2026-11-11): the capability is
this file plus a renderer already on the machine, found by the capacity plan
(`lib/generative-capacity.mjs`). The camera, light and resolution live in this file's `inputs`,
so a better look is an edit to this file, not to code.

The conductor never starts a program. The render itself is therefore a DECLARED step: the trace
records the command and the reason. No picture is claimed until one exists.

## Steps (prose mirror)

1. **check-blender** — Is `blender` on PATH or in a usual place? Existence and executable bit only; it is not run.
2. **inspect-workdir** — Record the working folder's state before writing into it.
3. **render-scene-script** — Write `scene.py`: an empty scene, a ground plane, the subject as extruded text, one area light, one camera, Cycles at the ordered sample count and resolution, rendering to `<outputName>.png`.
4. **write-job** — Write `job.json`: the order as a record — subject, script, output, resolution, samples, the tool path, and the state `script-written-render-declared`.
5. **verify-artifacts** — Re-read both files and confirm the ordered resolution and samples landed in the script and the job record names it.
6. **declare-render** — DECLARED: the headless Blender command, with the reason it did not run here.

## Failure modes

- **Blender is not installed** → step 1 reports `found: false`. The script and job record are still written and verified; the declared command names `blender` and will work once it is installed.
- **The subject contains a quote, a backslash, a hash sign or a line break** → it would end the script's text literal or its comment early. The capacity plan removes those before the subject reaches this file (`safeSubject` in `lib/generative-capacity.mjs`); any other caller must pass a subject of plain words.
- **A render is wanted now** → this version does not run one. Starting a program from a method file is a separate, governed step the owner has not approved.
